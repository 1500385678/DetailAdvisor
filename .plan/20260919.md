### 主交付 · audit-scenarios v0.2.2 PRD 多关键词权重排序可视化与日志输出增强

`app/api/audit/scenarios/route.ts` 新增:

1. **meta 字段扩展(3 字段)**:
   - `prd_weighted_top_scenario: string | null` — v0.2 子场景中 hit_count 最高者;无命中时为 null
   - `prd_weight_distribution: Record<string, number>` — 权重分布,如 `{1: 2, 2: 1, 4: 1}` 表示 hit_count=1 的有 2 条,=2 的有 1 条,=4 的有 1 条
   - `prd_keyword_density: number` — PRD 关键词命中率(命中的 v0.2 子场景数 / v0.2 总子场景数),如 0.6 = 5 条子场景中命中 3 条

2. **console.log 日志增强**(POST handler 内):
   - 当 `prdMatchedScenarios.length > 0` 时,输出 1 行日志,包含:
     - feature 名
     - prd 文本长度
     - 命中的 v0.2 子场景数
     - 命中的关键词数(prdKeywordsMatched.length)
     - 权重最高的 v0.2 子场景 ID + hit_count
     - 被豁免的 v0.2 子场景 ID(若有)

3. **API_VERSION 升级**:`0.2.1-...` → `0.2.2-...+权重排序可视化+日志输出增强`
