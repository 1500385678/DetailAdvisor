## 决策依据

- **R-READ-01 选为首发规则的原因**:
  1. **零外部依赖**:纯字符统计,无字典/无 LLM/无 API key,工程端到端可入库
  2. **最高测试覆盖**:边界明确(28 / 40 字符),好坏例易造,易做单元测试

  4. **零误报风险**:纯字面统计,无 LLM 介入,不会出现 v0.1 错别字那种"同音字字典不全"问题
  5. **为后续规则铺路**:API 骨架先稳定,后续 v0.1 错别字 / v0.2 品牌词 / v0.3 语气按"加一个 rules 数组元素"的模式增量扩展
