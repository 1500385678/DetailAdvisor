### feat(audit-api): 启动 Phase 1 §6 模块 3 异常场景发现器 API 雏形 v0.1

- 新增 `app/api/audit/scenarios/route.ts`
  - Next.js 16 Route Handler · POST + GET 双端点
  - 5 类 28 条异常场景库(零依赖纯模板):
    - boundary(边界值)8 条:SC-B-01 ~ SC-B-08
    - concurrency(并发)5 条:SC-C-01 ~ SC-C-05
    - network(网络)5 条:SC-N-01 ~ SC-N-05
    - permission(权限)5 条:SC-P-01 ~ SC-P-05
    - device(设备)5 条:SC-D-01 ~ SC-D-05
  - 每条含 id / category / title / description / trigger / expected / severity / applicable_to / keywords 9 字段
  - severity 4 档:low / medium / high / critical
  - request:`{ feature: string (必填 ≤ 200), prd?: string, categories?: Category[] }`
  - response:`{ feature, total_scenarios, by_category: Record<5 类, Scenario[]>, score_complexity: 1-5, summary, meta: { api_version, feature_keywords_matched, categories_*, scenarios_per_category, filter_mode } }`

  - score_complexity 评分规则(1-5 基于返回场景数 + 命中类别数)
  - 错误响应:400 INVALID_JSON / MISSING_FEATURE / FEATURE_TOO_LONG / INVALID_CATEGORIES / INVALID_CATEGORY_VALUE
