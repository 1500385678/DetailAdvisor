## 1. 范围与设计

异常场景发现器定位:针对一个功能(feature),自动生成 5 类常见异常场景,辅助 QA/PM 在设计/开发阶段对齐"应该测什么"。v0.1 是**零依赖纯模板**:5 类异常场景库是静态常量,API 调用时按 feature 关键词做命中提示,无命中则返回全清单。

**5 类**:

| 类别 | 英文 | 含义 | 场景数 |
|------|------|------|--------|
| 边界值 | boundary | 输入字段的边界条件(空/极大/极小/特殊字符/0/负数/精度) | 8 |
| 并发 | concurrency | 多用户/多端/多请求同时操作的竞争场景 | 5 |
| 网络 | network | 弱网/断网/超时/DNS/代理等网络异常 | 5 |
| 权限 | permission | 未登录/权限不足/Token 过期/越权/角色变更 | 5 |
| 设备 | device | 老旧机型/低分辨率/触屏/横竖屏/系统版本 | 5 |

**合计 28 条**。每条字段:id / category / title / description / trigger / expected / severity(4 档 low/medium/high/critical)/ applicable_to(空 = 全适用,v0.1 全空)/ keywords(用于 v0.2 关键词匹配)。

## 2. 场景 ID 命名约定

- `SC-B-NN`:boundary 边界值场景(NN 两位数字 01-99)
- `SC-C-NN`:concurrency 并发场景
- `SC-N-NN`:network 网络场景
- `SC-P-NN`:permission 权限场景
- `SC-D-NN`:device 设备场景

后续扩展(SC-*-NN):
- 行业子规则:SC-EC-*(电商)/ SC-ED-*(教育)/ SC-FI-*(金融) 等(v0.3 计划)
- 性能子规则:SC-PERF-*(Lighthouse/性能预算,v0.2 计划)

## 3. 场景库详情

### 3.1 boundary 边界值(8 条)

#### SC-B-01 空输入
- 描述:所有文本输入框必填校验
- 触发:用户提交时输入框为空
- 预期:显示必填提示,不允许提交
- 严重度:**high**
- 关键词:输入 / 表单 / 提交 / 填写 / 账号 / 密码 / 手机号 / 邮箱 / 搜索

#### SC-B-02 极大输入
- 描述:长字符串/超大文件/批量数据上限校验
- 触发:用户输入超过字段上限的字符串或上传超大文件
- 预期:前端截断提示 + 后端 413 Payload Too Large
- 严重度:medium
- 关键词:输入 / 上传 / 文件 / 图片 / 视频 / 评论 / 简介 / 描述

#### SC-B-03 极小输入
- 描述:数值/金额字段下溢(负数/0/极小浮点)校验
- 触发:用户在金额/数量/长度字段输入 0 或负数或 0.001
- 预期:显示下限提示(如"金额需大于 0")
- 严重度:medium
- 关键词:金额 / 价格 / 数量 / 长度 / 重量 / 距离 / 步长 / 页码

#### SC-B-04 特殊字符
- 描述:XSS/SQL 注入/emoji/控制字符/Unicode 边界
- 触发:用户输入 `<script>` / `' OR 1=1--` / 🎉 / `\u0000` 等
- 预期:前端转义 + 后端参数化查询,不破坏布局
- 严重度:**high**
- 关键词:输入 / 评论 / 昵称 / 搜索 / 用户名 / 标签

#### SC-B-05 纯空白内容
- 描述:全空格/全换行/全标点的"无意义内容"校验
- 触发:用户提交" "(全空格)或"...."(全句号)
- 预期:识别为无效输入,提示"请输入有效内容"
- 严重度:low
- 关键词:评论 / 反馈 / 搜索 / 描述 / 备注

#### SC-B-06 数值溢出
- 描述:前端 number 类型最大值越界
- 触发:用户输入 99999999999999999999 等超大数字
- 预期:前端精度丢失提示,后端大数(BigInt/Decimal)处理
- 严重度:medium
- 关键词:金额 / 数量 / ID / 订单号 / 价格 / 积分

#### SC-B-07 日期边界
- 描述:起止日期倒置/跨年/闰年/夏令时/时区差异
- 触发:用户选择"结束日期早于开始日期"或"开始日期 = 1970-01-01"
- 预期:日期校验提示,前后端时区统一(建议 ISO 8601 + UTC)
- 严重度:medium
- 关键词:日期 / 时间 / 预约 / 订单 / 行程 / 开始 / 结束 / 有效期

#### SC-B-08 列表为空/超长
- 描述:空列表渲染/超长列表性能/分页边界
- 触发:接口返回 0 条 / 100 万条数据
- 预期:0 条显示空状态,1 万+ 走分页/虚拟滚动
- 严重度:low
- 关键词:列表 / 订单 / 评论 / 消息 / 商品 / 搜索结果 / 历史

### 3.2 concurrency 并发(5 条)

#### SC-C-01 重复提交
- 描述:用户多次点击提交按钮导致重复创建订单/记录
- 触发:网络慢时用户连续点击提交按钮 3+ 次
- 预期:首次点击后按钮置灰,接口幂等性设计(Idempotency-Key)
- 严重度:**high**
- 关键词:提交 / 创建 / 下单 / 支付 / 注册 / 报名 / 申请

#### SC-C-02 多端登录冲突
- 描述:同一账号在多端(Web/iOS/Android)同时登录导致数据竞争
- 触发:用户 A 端登录后又从 B 端登录,A 端继续操作
- 预期:A 端踢下线提示,或 A 端数据实时同步
- 严重度:**high**
- 关键词:登录 / 账号 / 会话 / token / 授权

#### SC-C-03 并发读写冲突
- 描述:两人/多账号同时编辑同一资源(协同文档/库存)
- 触发:运营 A 和 B 同时修改同一商品库存
- 预期:乐观锁/悲观锁,后写入者收到"已被修改"提示
- 严重度:**high**
- 关键词:编辑 / 修改 / 更新 / 库存 / 文档 / 协同 / 状态

#### SC-C-04 秒杀超卖
- 描述:限量商品 100 件,200 人同时下单导致超卖
- 触发:活动开始瞬间 200 并发请求 100 件库存
- 预期:Redis 原子减库存 / 数据库行锁,严格 100 件
- 严重度:**critical**
- 关键词:秒杀 / 抢购 / 限量 / 库存 / 活动 / 下单 / 优惠

#### SC-C-05 接口重复调用
- 描述:前端组件 mount 多次 / React 18 strict mode 触发重复请求
- 触发:组件 useEffect 依赖错误导致 mount 多次发请求
- 预期:请求去重(AbortController)+ loading 状态防抖
- 严重度:medium
- 关键词:接口 / 请求 / 列表 / 详情 / 加载

### 3.3 network 网络(5 条)

#### SC-N-01 弱网延迟
- 描述:2G/3G/电梯/地铁场景下请求 10s+ 才返回
- 触发:用户在弱网环境提交表单
- 预期:loading 状态 + 超时提示(>10s)+ 请求可取消
- 严重度:**high**
- 关键词:提交 / 上传 / 加载 / 请求 / 接口

#### SC-N-02 断网
- 描述:用户飞行模式/电梯/地下室完全无网
- 触发:提交瞬间网络断开
- 预期:网络断开提示 + 本地草稿保存 + 重连自动重试
- 严重度:**high**
- 关键词:提交 / 上传 / 加载 / 请求

#### SC-N-03 接口超时
- 描述:服务端 504/502 或 30s+ 无响应
- 触发:后端服务宕机或数据库慢查询
- 预期:前端超时提示(30s)+ 自动重试 1 次 + 失败埋点
- 严重度:medium
- 关键词:接口 / 请求 / 加载

#### SC-N-04 DNS 解析失败
- 描述:域名劫持/DNS 污染/host 失效
- 触发:用户处于被劫持网络环境
- 预期:前端 HTTPS 强制 + 备用域名/IP 兜底
- 严重度:low
- 关键词:接口 / 请求 / 域名 / API

#### SC-N-05 代理/VPN 异常
- 描述:企业代理拦截/校园网认证/海外地区访问
- 触发:用户在企业内网访问公网
- 预期:友好错误页 + 备选方案(扫码/H5 备用入口)
- 严重度:low
- 关键词:接口 / 请求 / 访问 / 公网

### 3.4 permission 权限(5 条)

#### SC-P-01 未登录访问
- 描述:未登录用户访问需登录页面/接口
- 触发:用户直接打开需登录 URL 或点击深链
- 预期:跳转登录页 + 登录成功后回到原 URL
- 严重度:**high**
- 关键词:页面 / 详情 / 个人中心 / 订单 / 评论 / 设置

#### SC-P-02 权限不足
- 描述:普通用户访问仅管理员可见的功能/数据
- 触发:普通用户访问 /admin/* 或他人订单详情
- 预期:403 提示页 + 申请权限入口(如有)
- 严重度:**high**
- 关键词:管理 / 编辑 / 删除 / 查看 / 他人 / 订单 / 后台

#### SC-P-03 Token 过期
- 描述:JWT/session 过期(常见 7d/30d)
- 触发:用户长期未操作后再次操作
- 预期:静默刷新 token + 失败时跳转登录 + 保留原页面状态
- 严重度:**high**
- 关键词:登录 / 账号 / token / 会话 / 请求

#### SC-P-04 越权操作
- 描述:通过修改 URL 参数/接口 body 越权操作他人数据
- 触发:用户修改 orderId 从 1001 到 1002 查看他人订单
- 预期:后端鉴权校验(用户 ID 与资源所属用户比对)
- 严重度:**critical**
- 关键词:详情 / 编辑 / 删除 / 查看 / 订单 / ID / 参数

#### SC-P-05 角色变更
- 描述:用户角色在操作中变更(从普通用户提升/降级)
- 触发:管理员在后台将用户从普通提升为 VIP,用户当前页面正在操作
- 预期:下次接口请求返回新角色权限,前端按需重渲染
- 严重度:medium
- 关键词:角色 / 权限 / VIP / 会员 / 状态

### 3.5 device 设备(5 条)

#### SC-D-01 老旧机型
- 描述:iPhone 6s/8 等老机型/Android 4.4 性能不足
- 触发:老机型用户打开动画/视频多的页面
- 预期:降级动画/低清视频/关闭动效以保证流畅
- 严重度:medium
- 关键词:页面 / 视频 / 动画 / 图片 / 加载

#### SC-D-02 低分辨率
- 描述:小屏(320px 以下)/大屏(2K+)/平板横屏
- 触发:用户使用 320px 宽屏或 2560×1440 显示器
- 预期:响应式布局 + 字体/图片自适应
- 严重度:low
- 关键词:页面 / 布局 / 图片 / 文字

#### SC-D-03 触屏 vs 鼠标
- 描述:hover 态在触屏设备失效/点击延迟 300ms
- 触发:用户使用移动设备访问依赖 hover 的网页
- 预期:触屏优先(无 hover 依赖)+ tap 高亮 + viewport meta
- 严重度:medium
- 关键词:页面 / hover / 菜单 / 按钮 / 链接

#### SC-D-04 横竖屏切换
- 描述:用户旋转设备导致布局错乱/数据丢失
- 触发:用户填写表单中途旋转屏幕
- 预期:横竖屏自适应 + 表单数据持久化(localStorage)
- 严重度:low
- 关键词:页面 / 表单 / 视频 / 游戏 / 地图

#### SC-D-05 系统版本差异
- 描述:iOS Safari/WebView 与 Android Chrome/WebView 兼容性
- 触发:iOS 14- 与 Android 6- 旧版 WebView 渲染异常
- 预期:CSS 前缀/Polyfill + 关键路径在最低支持版本测试
- 严重度:medium
- 关键词:页面 / 兼容性 / 渲染 / WebView / 浏览器
